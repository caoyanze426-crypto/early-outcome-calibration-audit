# Early Outcome Calibration Audit

Reproducibility materials for a reliability audit of target-specific calibration transfer in trajectory-based early outcome prediction for LLM agents.

## Repository status

This repository is being prepared as the public reproducibility package for Paper 2. Scientific results are frozen; this repository will contain author-owned analysis code and derived artifacts only.

## Scope

Planned contents include:

- analysis code developed for this study;
- derived aggregate results used in the paper;
- figure and table source data;
- publication figures and tables;
- selected study protocols and reproducibility metadata.

Raw third-party SWE-bench Verified and TerminalBench trajectories are **not redistributed** here. Their source datasets, frozen revisions, and licenses are documented in `THIRD_PARTY_NOTICES.md`.
